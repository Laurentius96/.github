# Getting Help

- **Questions about a project:** start with its README, which explains what it does, how to run it and how the results were obtained.
- **Something does not work:** [open an issue](../../issues/new/choose) in the repository with the steps to reproduce it.
- **Anything else** (collaboration, opportunities or feedback): send me a message on [LinkedIn](https://www.linkedin.com/in/cb-lorenzo/).
