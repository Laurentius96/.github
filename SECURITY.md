# Security Policy

## Reporting a vulnerability

If you find a security problem in any of my repositories (for example, an exposed credential, an unsafe dependency or a way to make a script leak data), **please do not open a public issue**.

Report it privately instead:

- through **GitHub private vulnerability reporting**, using the **Report a vulnerability** button in the repository's **Security** tab, when it is available; or
- through a private message on [LinkedIn](https://www.linkedin.com/in/cb-lorenzo/).

Please include the repository, the file or step involved, and how the problem can be reproduced. I will acknowledge the report as soon as possible and keep you informed while it is fixed.

## Scope

These repositories are portfolio and study projects, not production services. They are maintained on a best-effort basis, and only the latest version on the `main` branch is supported.
